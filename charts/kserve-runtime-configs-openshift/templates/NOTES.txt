KServe LLM runtime configs {{ .Chart.AppVersion }} installed as release {{ .Release.Name }} in {{ .Release.Namespace }}.

  oc get llminferenceserviceconfig -n {{ .Release.Namespace }}

An LLMInferenceService picks these up through spec.baseRefs, for example:

  spec:
    baseRefs:
      - name: kserve-config-llm-template

The vLLM and llm-d container images inside these presets are hardcoded by
upstream and are not overridable by any Helm value. In a disconnected cluster
they resolve only through the ImageDigestMirrorSet that `oc mirror` generates
from mirror-config.yaml. List them with:

  oc get llminferenceserviceconfig -n {{ .Release.Namespace }} -o yaml \
    | grep -oE 'image: \S+' | sort -u
